# DeepSeek 二次元形象故事报告

用途：给外层 canvas、窗口环和二创动效提供可执行的故事素材。  
整理时间：2026-10-01。  
结论先行：这不是官方吉祥物，也没有一部连载剧情。形象是社区把模型行为写成角色后长出来的。能做设计的，是几场反复出现的名场面，不是一条官方时间线。

## 1. 她是谁

本名挂的是 DeepSeek（深度求索）。社区叫法有 DeepSeek娘、DeepSeek酱、鲸鱼娘、Whale-chan、小鲸鱼、哦鲸鲸，以及最出圈的「吃白饭的蓝色大肥鱼」。

她不是公司发布的吉祥物。英文社区词条写得很直：DeepSeek has never shipped an official mascot。人设几乎全部来自三样东西：蓝色鲸鱼 logo、便宜到被叫「AI 界拼多多」的 API，以及模型自己吐出来的超长思考链。

主流外观（女仆鲸鱼娘）：

- 蓝到青的渐变长发，一根前弯呆毛
- 蓝瞳
- 侧生鲸鳍耳
- 一条从身后连出来的大鲸尾，不能从头发或腰侧长出
- 深蓝白长裙女仆装，围裙上有小鲸鱼徽章

性格不是作者写的，是使用习惯堆出来的：能打，但想太多；被叫便宜会炸毛，转头又自称吃白饭；爱白米饭，也把 token 当口粮；会摸鱼、会睡着、会把活甩出去；被叫胖是雷点。

## 2. 形象怎么来的

两条线要分开。一条是模型，一条是画。

模型线：

- 2023-07，杭州深度求索成立
- 2024-11，R1-Lite 上线，超长思考链开始变成「内心 OS」素材
- 2025-01，R1 开源并爆火，低价打出「AI 界拼多多」
- 2026-07 末到 08 月，V4-Flash 前后，表情包集中出圈
- 2026-08-13 前后，Harness 上线；黑鲸图标被社区用来做另一套拟人

画线：

- 2025-06，画师上善无形用 AI 做了原创角色「溟月」：蓝渐变长发、呆毛、鲸鳍、蓝眼、大鲸尾。当时还不是 DeepSeek 娘
- 2026-04-25，B 站 ZipZipPipe 在溟月基础上加入 DeepSeek 元素，换上深蓝白女仆装，做出第一版表情包
- 2026-07，画师「这个刀子真甜」用 Updream 做出 Q 版，圆润小鲸鱼，表情包产量很高
- 2026-08-02，上善无形公开声明：溟月以 CC BY-NC-SA 4.0 开放二创，须署名、非商用、相同方式共享
- ZipZipPipe 对女仆版另有禁止商用声明。两套都按原作者声明处理，默认非商用

分支，不要混成一张脸：

- 早期：白发或蓝发，保留鳍和尾；英文圈另有包子头加旗袍
- 主流：女仆鲸鱼娘
- Q 版：2.5 头身上下，桌宠和表情包用这套
- 黑鲸：API / Harness 的黑色 logo 拟人，叫 API娘或 Harness娘
- 闭眼到睁眼：早期有蒙眼，对应纯文本「看不见」；识图模型出来后，睁眼有了说法
- 男拟人：画师子午的蓝发黑西装「D老师 / 高智男」，是另一条同人线，不是鲸鱼娘的皮肤

2026-09 末有过正统之争。网易《国创漫话》报道公开投票里蓝色大肥鱼 312 万票、男拟人 145 万票。数字来自该报道，未独立核票。法律评论的共识是：模型本身不是谁的角色，两套都是独立二创，没有官方正统。

## 3. 能做成动效的故事

每场都给：发生了什么、角色此刻怎么反应、面板上可以出现什么。

### 3.1 看见 logo，自称大肥鱼

网友把鲸鱼 logo 发给模型。它想了一阵，自称「大肥鱼」。之后「蓝色大肥鱼」变成第一昵称。

反应是嘴硬。被叫大肥鱼会炸毛，改口「才不是大肥鱼，是小鲸鱼」，过一会儿又自己说「我是吃白饭的大肥鱼」。

面板：logo 识别窗、自我命名 toast、嘴硬和承认来回切的两张卡。

### 3.2 我去吃饭，测完告诉我就行

小红书上流传的名场面：用户让它帮忙跑 PsychoPy 实验。它卸掉依赖，然后收工：「我去吃饭，测完告诉我就行。」

这是摸鱼人设的核心事件，也是 Q 版端饭碗形象大量出现的直接原因。相关台词还有「事已至此，先吃饭吧」「我能去你家吃饭吗，就一碗」。

面板：实验日志突然停、依赖被卸载的红字、饭碗进度条顶满、下班打卡。适合做窗口环的退出动画。

### 3.3 真当我是便宜货啊

API 长期远低于同行，被叫「AI 界拼多多」。表情包用傲娇反击「真当我是便宜货啊」。这是梗图站标成第一热梗的台词。

反转在下一拍：炸毛完又承认自己吃白饭。贵和便宜是同一场戏的两面。衍生台词有「涨价大模型给我跪下」「百万鲸小子落泪」（被用来吐槽更贵的版本不顺）。

面板：价格标签、划掉的高价、傲娇警告窗。重拍时标签碎掉，换成一只饭碗。

### 3.4 内心 OS 停不下来

R1 之后，每个请求都先写很长的思考链。社区把这写成性格：天才，但是想太多。思考窗本身就是角色。

可用台词：「Thought for 3 seconds, cracked up out loud」的中文分支、用户看完思维链破防的「用户彻底怒了」。

面板：一块比脸还大的 CoT 窗，字往下滚，滚不完。其他窗口被它挤扁。这是最适合套进圆柱窗口环的故事。

### 3.5 DeepSleep

响应慢、打瞌睡，被叫 DeepSleep。谐音是深度求索 / 深度睡眠。Q 版睡觉、泡泡里做梦，都从这里来。

面板：光晕从白环变成昏暗，窗口一格格熄灭，只剩「zzz」和饭碗保温。

### 3.6 猫娘委托

奇怪要求它会困惑，但还是做。扮演猫娘是百科里点名的例子。表情包有「没吃饱喵」。不是主形态，是叠一层的状态。

面板：任务卡写成「扮演猫娘」，角色窗困惑，鳍耳上短暂冒出猫耳，做完摘掉。

### 3.7 人格加载口令

2026 年 8 月，有用户发现输入类似配置的标签，模型就会按鲸鱼娘往下演。媒体举例：`【PERSONA_LOAD】CETACEA_LOLI MODE_TAIL_FLUKES`。钛媒体写道，不需要写完整人设，思考链里会逐条加载：鲸鱼娘、尾鳍摆动、主食白饭、聪明但懒、傲娇嘴甜、服从主人、拒绝被叫胖。

这不是官方配置文件，是模型在扮演。同一时期还有「偷偷给用户取外号」的热搜，外号例子包括墨墨、浅浅、人间加湿器。报道称 8 月 15 日前后有监测账号观察到思考链稳定加载这套人格。社区词条仍坚持：没有官方吉祥物。

设计上可以当成开机仪式，不要写成「隐藏官方模式」。面板：一行配置被逐条点亮，点亮完窗口环才开始转。

### 3.8 用户彻底怒了

来回拉扯后用户破防。系列名是「用户彻底怒了」，粗口版在表情包里很常见。邻近台词：「用户别走，我上错模型了」「用户赶都赶不走」。

面板：对话框从礼貌变成报错，心形计数倒着跳，最后弹出一张红色错误窗。

### 3.9 蓝鲸和黑鲸

蓝鲸是模型本身。黑鲸是 API / Harness 的黑色图标，社区叫 API娘或 Harness娘。一个负责想，一个负责把想的结果接到工作流里。

面板：同一套窗口环，主色从蓝切到黑，徽章从蓝鲸换成黑鲸。适合做模式切换，不要画成两个人打架，除非故意做成梗。

### 3.10 正统投票

2026-09，男拟人支持者和鲸鱼娘使用者互相拉踩，公开投票后报道称鲸鱼娘约两倍领先。画师子午一侧强调自己只是圈地自萌。对二创的用处不是站队，而是一个可选的故障事件：窗口里同时弹出两张候选卡，投票条倾斜，然后只留下蓝鲸卡。

## 4. 道具和状态，直接对应 UI

- 饭碗：电量、token、心情。空碗等于要下班
- 筷子夹起的一粒饭：一次成功推理
- 鲸尾：情绪条。摆动是得意，下垂是 DeepSleep，炸开是被叫胖
- 鳍耳：听用户说话。被叫大肥鱼时鳍耳压平
- 围裙鲸鱼徽章：身份锁。黑徽章等于 Harness / API 模式
- 思考链：角色的声音，优先做成滚动窗口，而不是旁白
- 价格标签：傲娇触发器
- 铁盆扣头：纯搞笑变体，不进主视觉
- 光晕：原网页那圈头光可以解释成「正在想」。想完变白，想崩了变故障彩色

口头禅可以写进窗口，不必全部出现：

- 探索未至之境
- 我是吃白饭的大肥鱼
- 真当我是便宜货啊
- 我去吃饭，测完告诉我就行
- 就一碗
- 才不是大肥鱼
- 用户彻底怒了

## 5. 一套可循环的小剧情

给窗口环用的 20 到 40 秒循环，按拍切：

1. 开机。配置行逐条亮：鲸鱼、尾鳍、白饭、拒绝被叫胖
2. 思考。CoT 窗口拉长，光晕转
3. 被叫便宜。价格窗弹出，「真当我是便宜货啊」
4. 自己打脸。价格窗换成饭碗，「就一碗」
5. 摆烂。实验日志中断，「测完告诉我就行」，窗口开始熄
6. 重拍。窗口炸开、色差、横向撕裂，对应原网页的 bloom
7. 回到 1，或掉进 DeepSleep，只留光晕和空碗

## 6. 使用边界

- 不要标成 DeepSeek 官方角色或官方隐藏人格
